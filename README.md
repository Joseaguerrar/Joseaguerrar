# 📂 Selected Projects

### ⚙️ Dual-Core RISC-V Processor

Designed and developed a dual-core processor as part of a team project,
exploring concurrent execution and how multiple processing units coordinate
access to shared resources.

### 🧵 Parallel Heat Transfer Simulation

Developed a numerical heat-transfer simulation and redesigned it for parallel
and distributed execution, experimenting with workload distribution,
synchronization, and performance.

### 🛠️ Compiler Development

Led a three-person team in the development of a compiler written in C,
taking a small programming language from source code to executable programs.

I have also worked on lexical analysis, preprocessing, parsing, and structured
language-processing projects.

### 🧩 Computability & Complexity

Worked on computationally difficult problems involving algorithms,
optimization, and computational complexity.

These projects included comparing exact, greedy, and metaheuristic approaches,
including Simulated Annealing, for solving constrained optimization problems.

### 🧠 Artificial Intelligence

Worked with real-world datasets to preprocess information, train predictive
models, tune parameters, and compare machine-learning approaches.

One project focused on predicting rainfall in Australia using multiple
meteorological variables.

### 🧪 Design of Experiments

Designed controlled experiments to compare machine-learning models and analyze
how different factors and their interactions influence predictive performance.

This work combines statistical experimentation with software and machine learning
to evaluate results systematically.

### 💻 Operating Systems

Extended the NachOS educational operating system while exploring memory management,
processes, threads, system calls, virtual memory, and network communication.

### 🌐 Distributed & Networked Systems

Developed client-server and distributed software using sockets, TCP/UDP,
IPv4/IPv6, service discovery, and secure communication.
